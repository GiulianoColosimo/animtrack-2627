Foundational reading

The papers below are the ones actually worth reading in full. Each is tied to the class where it becomes relevant.

Movement ecology (Class 1)

  • Nathan R, Getz WM, Revilla E, Holyoak M, Kadmon R, Saltz D, Smouse PE (2008). A movement ecology paradigm for unifying organismal movement research. PNAS 105:19052–19059. doi:10.1073/pnas.0800375105 — the framework the whole field hangs on: internal state, motion capacity, navigation capacity, external factors.
  • Kays R, Crofoot MC, Jetz W, Wikelski M (2015). Terrestrial animal tracking as an eye on life and planet. Science 348:aaa2478. doi:10.1126/science.aaa2478
  • Hebblewhite M, Haydon DT (2010). Distinguishing technology from biology: a critical review of the use of GPS telemetry data in ecology. Phil Trans R Soc B 365:2303–2312. doi:10.1098/rstb.2010.0087 — read this before you trust any GPS dataset.

Tag effects and ethics (Class 1)

  • Wilson RP, McMahon CR (2006). Measuring devices on wild animals: what constitutes acceptable practice? Front Ecol Environ 4:147–154.
  • Portugal SJ, White CR (2018). Miniaturization of biologgers is not alleviating the 5% rule. Methods Ecol Evol 9:1662–1666. doi:10.1111/2041-210X.13013

Spatial data in R (Classes 2–3)

  • Geocomputation with R — Lovelace, Nowosad, Muenchow. Free, excellent, the default recommendation.
  • Spatial Data Science with applications in R — Pebesma & Bivand, by the author of sf.
  • rspatial.org — Hijmans, the terra reference.
  • Movebank’s data documentation.

Home range and space use (Class 4)

  • Powell RA, Mitchell MS (2012). What is a home range? J Mammal 93:948–958. doi:10.1644/11-MAMM-S-177.1
  • Fleming CH, Fagan WF, Mueller T, Olson KA, Leimgruber P, Calabrese JM (2015). Rigorous home range estimation with movement data: a new autocorrelated kernel density estimator. Ecology 96:1182–1188. doi:10.1890/14-2010.1 — why classical KDE under-estimates when fixes are autocorrelated, and what AKDE does about it.
  • Signer J, Fieberg J, Avgar T (2019). Animal movement tools (amt): R package for managing tracking data and conducting habitat selection analyses. Ecol Evol 9:880–890. doi:10.1002/ece3.4823

Remote sensing (Class 5)

  • Pettorelli N, Vik JO, Mysterud A, Gaillard J-M, Tucker CJ, Stenseth NC (2005). Using the satellite-derived NDVI to assess ecological responses to environmental change. TREE 20:503–510. doi:10.1016/j.tree.2005.05.011
  • Neumann W, et al. (2015). Opportunities for the application of advanced remotely-sensed data in ecological studies of terrestrial animal movement. Movement Ecology 3:8.
  • Data portals: Copernicus Browser (Sentinel), USGS EarthExplorer (Landsat), NASA AppEEARS (MODIS/VIIRS point-and-area extraction), Movebank Env-DATA (annotates your track automatically — start here), WorldClim, Copernicus Global Land Cover.

Segmentation and behavioural states (Class 6)

  • Patterson TA, Basson M, Bravington MV, Gunn JS (2009). Classifying movement behaviour in relation to environmental conditions using hidden Markov models. J Anim Ecol 78:1113–1123.
  • Langrock R, King R, Matthiopoulos J, Thomas L, Fortin D, Morales JM (2012). Flexible and practical modeling of animal telemetry data: hidden Markov models and extensions. Ecology 93:2336–2342. doi:10.1890/11-2241.1
  • Michelot T, Langrock R, Patterson TA (2016). moveHMM: an R package for the statistical modelling of animal movement data using hidden Markov models. Methods Ecol Evol 7:1308–1315.
  • A guide to state-space and hidden Markov modelling — Michelot & Langrock’s moveHMM vignette is the most practical starting point.
  • Edelhoff H, Signer J, Balkenhol N (2016). Path segmentation for beginners: an overview of current methods for detecting changes in animal movement patterns. Movement Ecology 4:21.

Resource and step selection (Classes 7–8)

  • Boyce MS, Vernier PR, Nielsen SE, Schmiegelow FKA (2002). Evaluating resource selection functions. Ecol Modelling 157:281–300.
  • Fieberg J, Signer J, Smith B, Avgar T (2021). A “how-to” guide for interpreting parameters in habitat-selection analyses. J Anim Ecol 90:1027–1043. doi:10.1111/1365-2656.13441 — the single most useful paper in this course. Read it twice.
  • Avgar T, Potts JR, Lewis MA, Boyce MS (2016). Integrated step selection analysis: bridging the gap between resource selection and animal movement. Methods Ecol Evol 7:619–630. doi:10.1111/2041-210X.12528
  • Thurfjell H, Ciuti S, Boyce MS (2014). Applications of step-selection functions in ecology and conservation. Movement Ecology 2:4.
  • Muff S, Signer J, Fieberg J (2020). Accounting for individual-specific variation in habitat-selection studies. J Anim Ecol 89:80–92 — how to do this properly with more than one animal.

Books

  • Hooten MB, Johnson DS, McClintock BT, Morales JM (2017). Animal Movement: Statistical Models for Telemetry Data. CRC Press. The rigorous reference. Heavy on maths, worth it.
  • Fieberg J (2024). Statistics for Ecologists: A Frequentist and Bayesian Treatment of Modern Regression Models — free online, with excellent habitat-selection chapters.
  • Cagnacci F, Boitani L, Powell RA, Boyce MS, eds. (2010). Special issue on GPS telemetry, Phil Trans R Soc B 365(1550) — still the best single collection of overviews.

Software and communities

move2 Movebank access and the modern move successor
ctmm Continuous-time models, AKDE. Has a point-and-click app.
moveHMM / momentuHMM HMMs; momentuHMM for multiple data streams
adehabitatHR Classic home range estimators
sf / terra The spatial foundation
AniMove Annual summer school — the best training available in this field
Movebank Data repository; also hosts Env-DATA annotation

Getting help

When code breaks, in this order:

  1. Read the error message. Genuinely. Most R errors name the object and the function that failed.
  2. ?function_name and the package vignettes (browseVignettes("amt")) — these are written by the people who wrote the code.
  3. r-spatial on Stack Overflow and the amt GitHub issues.
  4. Ask me — but bring a reproducible example: the smallest piece of code plus the smallest piece of data that reproduces the problem. Building that example solves the problem about half the time by itself.
